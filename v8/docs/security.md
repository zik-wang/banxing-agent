# 私有评估与数据边界

本次按项目所有者明确指示发布私有仓库；未申请公开开源许可。仅提交代码、配置样例、合成单元测试及文档。不提交用户原件、真实聊天、私有部署配置、密钥、运行日志、QA 截图或历史 Git 数据。

- .env、.local-runtime、data、qa-output、node_modules、*.private.json 均排除。
- 旧部署适配器代码仍包含固定服务协议及地址校验；它们不是可用凭据。默认未配置模式不会触发发现或调用。真实部署配置留在本机。
- 模型没有任意 shell/文件路径工具。办公修改采用有限操作集合；成果及来源同对话校验，删除或排除的附件不可偷偷恢复。
- 当前成果和下载由文件存在、大小及 SHA256 校验；任务失败仍保留已核实的部分交付。
- 日历写入需明确确认，并绑定事件内容；改期/删除要求 Provider 的强版本标识，遇到并发修改拒绝覆盖。
- 当前是单机权限模型，不具备组织多租户认证、全面 RBAC 或第三方日历账号的生产验收。
- 发布扫描是有限模式检查，不构成无漏洞证明。未知材料的语义正确性需要独立参考答案。
