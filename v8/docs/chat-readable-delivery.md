# 对话内可读交付

统计任务在回复中直接显示记录数、去重数、相关数值合计及空值/冲突等待核项。原始回执、文件ID、SHA256、调用记录和未核实模型原答放在默认折叠的“技术回执与核对依据”中。下载、打开本地文件、资源管理器定位保留；完整路径另行折叠。复制回复使用可读内容。

展示使用 `table_statistics` 的完整结构化回执，不恢复未经校验的模型数字。十进制合计按字符串分组，不通过浮点转换；序号、编码等标识以及单价、比例等非可加指标不作为默认合计展示。失败、缺输入、缺文件和未完成事项不因排版被改成成功。

新交付把所用统计回执嵌入 settlement；历史对话按已登记的 receipt ID 读取本轮统计文件。读取限制在运行数据根目录、限制大小、校验回执内容摘要及已知成果版本。缺失或不一致时给出可读说明，原始证据仍可展开追查。缓存随实际文件版本变化失效，原始答案和产物均不重写。

普通聊天和用户主动请求的技术内容保持原样。本次改动不新增模型调用或导出动作，不生成独立展示页。前端持久保留轮询前已展开的技术回执。
