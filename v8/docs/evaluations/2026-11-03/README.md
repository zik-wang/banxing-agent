## 如何理解差距

发布简报是这次最明确的工程差异：同模型、同原件，Codex实际生成简报；伴行连续4次错误导出没有纠正。工具输出重复带回长JSON对象，也增加上下文开销。恢复使用新尝试，累计请求没有隐去初次失败；本轮没有测试Workspace断点续跑，不能据此断言该模块失效。

合同结果显示另一层限制：伴行保住17组字面字段但主清单漏了跨行协议年份；Codex补入该年份，却把协议名称当合同供应商，且引入无源时区判断。源码副本两边相同。文件交付、文字保存无损与业务正确性必须分开。

优先改进应集中在导出参数纠错、长JSON的按需字段复用、跨行事实与供应商角色约束；不能仅增加轮次或认为换框架就自动消除事实错误。
