V8-R2 controlled continuity (explicit opt-in)

Entry remains node v8-tools/run.mjs operator-config.json. The inherited V7 product entry is not used. Single-run configs remain compatible.

Host config adds continuity: {spaceRoot,projectId,workItemId,interactionId,selectedInputs:[{resourceId,revisionId}],selectedResult:{resourceId,revisionId}|null,mode:"revise"|"resume"|"retry"|"rebuild_delivery",resumeRunId,maxCumulativeModelRequests,maxCumulativeToolAttempts}. New runs require fresh directories. resume/retry use the saved request and input versions; new file inputs are rejected. Rules changing require a new revision rather than silently resuming old policy. Model calls and actual tool attempts share a root budget across resume processes. Pure rebuild_delivery does not request a model or repeat exports.

ResourceSpace is a host API, not a model tool. project/work/rules/select/exclude/revoke are host operations. select requires the current selectionRevision; a late run cannot overwrite a newer selection. Selected result is scoped to a work item. Explicitly selecting another authorized result creates a derived branch; the model cannot change project membership or add paths. Current table IDs survive serialization with full rows/types/nulls/provenance. Selecting a result restores the chosen merged table without loading the original assets. Checkpoints retain all intermediate objects for retry. Image/ASR intermediate recovery beyond generic saved objects is not accepted in R2.

Revocation policy: revoke a resource blocks descendants recursively. Excluding an original only changes requested/default inputs and does not revoke separately authorized derived outputs. Exclusions are configured by the host, not inferred by ad-hoc business phrase routing. Controlled runs discard historical model prose and construct current context anew; older legacy callers retain follow-up messages but receive fresh host guidance. Knowledge search in controlled mode requires a currently loaded authorized source ResourceRef, retaining separate source identities even for equal bytes; legacy knowledgeDirectory behavior remains available only outside controlled mode.

spaceRoot stores versioned hash-checked blobs and index.json schemaVersion=1. writer.lock is acquired synchronously with exclusive creation. Interrupted lock is an explicit blocker; do not blindly delete it while another process may be writing. Orphan blobs/temp files are not authorized resources. Recovery checks schema, resource hashes, paths, parent revocation, rules and input classification. No automatic schema migration is attempted. Host remains trusted; this is not an enterprise multi-tenant security boundary.

Operation intents persist before tool execution; operationId differs from each attemptId. Recovery is bounded to three attempts plus cumulative budgets. Deterministic source read/merge receipts may be reused only in the same root with matching arguments/input/rule/capability. Successful exports reuse saved receipts; export_table additionally journals file intent and file-written checkpoint before normal registration. Restart after file-written validates saved XLSX and registers the same artifactId. Missing/changed registered files are failures. Deterministic parsing is independent of model config, while snapshots record actual model config. Unknown external write outcomes are blocked, never resent; no actual external-write tool is introduced here.

Limitations: snapshots are JSON plus immutable blobs, not a database with multi-tenant auth. A full checkpoint is serialized after tools; large runs incur overhead. Other exporters lack a file-written intent window and may require manual rebuild; no automatic recovery promise for ASR/vision requests or external effects. Operation resume is bounded, not a background infinite loop. Content correctness is never inferred from file/hash integrity.

Executable demo: node scripts/v8-r2-demo.mjs host-config.json new-demo-root. Requires authorized reachable model, Python openpyxl, artifactModule. The script creates synthetic XLSX, starts three actual Node processes and passes only resource selection to run two. No script selects model tools. The final delivery query is deterministic. Independently check output business cells and provenance; CLI model_finished is not acceptance.

Deterministic interruption test: configure V8_PYTHON and V8_ARTIFACT_MODULE then node --test tests/v8-continuity.test.mjs. The child script explicitly invokes tools as a contract test, not a model result. testFault hooks are host-only isolated test config; never use them on shared services.
