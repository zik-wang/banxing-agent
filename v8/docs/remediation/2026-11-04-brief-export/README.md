# 阶段简报导出修复

旧案例 11 连续用 `source_ids` 调用 `export_document`，没有提供正文；来源标识不能替代简报。

修复后，启用 `executionRepair` 或 `documentComposition` 的宿主可将明确要求生成的叙述性简报交给报告编排：读取授权原件，让模型写正文，保存草稿，再导出并检查真实文件回执。没有指定格式时生成 Markdown；明确指定 Word/TXT 时遵守格式。禁止新文件、会议、外部操作、专项事实处理和不支持的格式继续走原有路径。宿主显式关闭 `documentComposition` 时不启用该路径。

“发布记录/快照”和“已发布成果”不再误触发发布操作；“不重新分析”不再触发重新撰稿。导出失败保留草稿，不能报告文件已生成。
