# 业务模块

从用户遇到的问题找到相应目录。网页入口和 V8 工具注册分别在 [v8-web](../v8-web/) 和 [v8-tools](../v8-tools/)。

| 目录 | 负责的工作 |
| --- | --- |
| [calendar](calendar/) | 日历服务、MCP 客户端和事件变更 |
| [conversations](conversations/) | 对话意图、后续修改、提醒 |
| [documents](documents/) | 附件、文档、电子表格、文件交付 |
| [evidence](evidence/) | 来源定位、文本对照、语义检查 |
| [invoices](invoices/) | 票据解析、字段核对、图像区域与批处理 |
| [media](media/) | 音频解码、视觉处理、多媒体读取记录 |
| [integrations](integrations/) | 模型配置、内网服务目录和外部连接 |
| [workspace](workspace/) | 工作区文件、场景处理与任务接单 |
| [recovery](recovery/) | 任务恢复、补查和重试 |
| [diagnostics](diagnostics/) | QA 事件、观察与构建标识 |
| [runtime](runtime/) | 基础运行时、数据锁和历史服务入口 |
