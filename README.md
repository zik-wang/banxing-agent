## 启动

需要 Node.js 22.19+（本轮使用 24.15）、npm。Windows 为实际验收平台。

```powershell
git clone https://github.com/zik-wang/banxing-agent.git
cd banxing-agent
npm ci --ignore-scripts
npm start
```

默认页面以控制台打印地址为准。可用环境变量 PORT 指定端口，例如 8814；DEMO_DATA_DIR 指定独立数据目录。没有模型配置时不会扫描旧公司网络或自动使用公网模型。已有 Excel 的格式转换及确定性编辑仍可使用；需要理解的新任务会明确提示模型未配置。

配置方法见 [部署](docs/deployment.md)。部署代码不包含真实发票、历史聊天、凭据或模型权重；私有验收材料另见下方2026-11-04说明；examples/mentor提供公司内网的无凭据连接样例。克隆不会自动获得本机 8814 的历史记录与内网访问权限。

## 连续操作

- 第一轮上传文件并交办；后续不用重新上传仍有效的材料。
- 成果卡直接下载 Word、Excel、PDF 或查看 HTML。只生成所要求的格式；PDF 依赖配置的转换服务。
- 页面“当前成果”可选择历史版本、恢复旧版并继续修改，也可更正某个字段。原件与旧成果保留。
- 表格修改支持补列、人工更正、改列名、排序、筛选、分组统计、去重、合并和生成有统计内容的报告。复杂说法通过 Qwen 转为受约束操作；程序负责读写、计算、来源范围和回读。
- 未理解的复合要求不会故意只做其中一种转换。缺少值时留空并提示待补；不能把“本轮文件完成”当成原始事实均正确。
- 失败后重试保留具体操作与来源；重复请求不重复创建任务；长对话历史持久保留并分页展示。
