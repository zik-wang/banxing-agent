# 伴行 V7 · Mentor 私有评估版

自然语言交办办公任务，后续只描述修改要求，继续修改当前成果并主动交付可下载文件。

本版本用于单机试用和 mentor 评估。28 个场景是入口数量，不是全部通过真实业务准确率验收的承诺。独立人工审定 Gold 数量仍为 **0**。

## 启动

需要 Node.js 22.19+（本轮使用 24.15）、npm。Windows 为实际验收平台。

```powershell
git clone https://github.com/zik-wang/banxing-agent.git
cd banxing-agent
npm ci --ignore-scripts
npm start
```

默认页面以控制台打印地址为准。可用环境变量 PORT 指定端口，例如 8814；DEMO_DATA_DIR 指定独立数据目录。没有模型配置时不会扫描旧公司网络或自动使用公网模型。已有 Excel 的格式转换及确定性编辑仍可使用；需要理解的新任务会明确提示模型未配置。

配置方法见 [部署](docs/deployment.md)。本仓库不包含真实发票、历史聊天、私有服务配置、凭据、模型权重或本机运行数据。克隆不会自动获得本机 8814 的历史记录与内网访问权限。

## 连续操作

- 第一轮上传文件并交办；后续不用重新上传仍有效的材料。
- 成果卡直接下载 Word、Excel、PDF 或查看 HTML。只生成所要求的格式；PDF 依赖配置的转换服务。
- 页面“当前成果”可选择历史版本、恢复旧版并继续修改，也可更正某个字段。原件与旧成果保留。
- 表格修改支持补列、人工更正、改列名、排序、筛选、分组统计、去重、合并和生成有统计内容的报告。复杂说法通过 Qwen 转为受约束操作；程序负责读写、计算、来源范围和回读。
- 未理解的复合要求不会故意只做其中一种转换。缺少值时留空并提示待补；不能把“本轮文件完成”当成原始事实均正确。
- 失败后重试保留具体操作与来源；重复请求不重复创建任务；长对话历史持久保留并分页展示。

## 日历

Calendar MCP 支持查询、冲突检查、提议、明确确认、创建及回读；对本对话创建的事件支持改期和取消，并检查事件版本。
目前真实外部账号 **未验收**。隔离 Provider 的测试只证明协议与本机流程。无需账号可按 config/calendar.example.json 配置隔离日历。CalDAV 账号接入后需另做真实验收。未读取他人日历不代表参会人有空；不发送邀请，不支持全天或重复事件。

## 评估

```powershell
npm run test:product
npm run test:release
```

自动测试包含模拟模型输出及隔离协议，不能替代真实模型或人工验收。[版本验收说明](docs/release-acceptance.md) 会分别记录。

请 mentor 使用自己未用于调参的获准文件测试。见 [评估方法](docs/mentor-evaluation.md) 和 config/mentor-evaluation-cases.json。30 项是待评估任务清单，**不是已经通过的 30 项盲测**。

## 备份与范围

停止服务后，使用 scripts/data-backup.mjs 备份或恢复到新目录；不要让两个实例写同一数据目录。本版仅监听回环地址，未实现面向互联网的多租户身份系统。

09 发票专用模块保留既有实现及独立运行器，完整识别依赖原部署提供的授权内网媒体配置。通用模型配置不会假装替代该专用配置；在其他机器未经配置不能承诺直接识别所有票据。模糊图像、角色关系和没有依据的影响仍可能需要人工核查。

这是按所有者指示建立的**私有仓库**。未选择开源许可证，不授予公开再分发许可。依赖许可证见 THIRD-PARTY-NOTICES.json；用户自行管理 mentor 访问权限。
