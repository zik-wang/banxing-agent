# P4实现边界

用户交办 → 现有Harness语义选择 → TaskIntake结构与文件门禁 → 既有Workspace处理器 → 原事实/来源验证 → 真实交付 → Presentation Adapter → 安全HTML及原始文件。

TaskIntake不是新的大Prompt或第二套业务执行器。它记录目标、场景、授权文件、关键缺项和状态。模型理解场景，程序检查注册能力、文件范围与输入约束。失败附件仍受同一对话与哈希控制，显式重试复用原件。

日历执行独立于业务文本提取：服务端保存提议；用户确认绑定事件哈希；通过标准MCP调用Provider；回读后更新卡片。模型没有批准工具。

HTML只使用程序模板填充已保存内容。原文、Markdown、模型内容均转义，不运行模型脚本。页面、文件存在、语义正确、业务完成是不同状态；partial和待核不得因美化而升级。
