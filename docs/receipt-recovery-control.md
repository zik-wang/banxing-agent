# 回执恢复的控制状态（2026-11-05）

公开归档命名场景07的冻结轨迹中，任务和计划仍在。两个PDF被读取为约10万字符的字段回执后，模型恢复原文；A回执已返回0–24000字符，压缩后的原回执提示仍从0开始。原工具的`nextOffset=100`是记录条目索引，恢复回执的`nextOffset=24000`是UTF-16字符偏移。数字年份被用作字符串查询时也出现两次真实参数错误。

新增按执行scope、实际callId、JSON pointer和原回执SHA绑定的范围台账。它原子保存已返回的历史文本区间，重启和显式回看不丢弃已取得的位置。压缩摘要会刷新恢复提示，并分别标明原工具记录分页与历史文本分页。到尾后提示指向末尾；显式offset=0仍可读取原字节。没有静默跳页或把回执覆盖当成原件、业务覆盖。

`get_execution_state`可返回这些控制元数据；私密本地政策或当前来源授权拒绝时，不向模型泄露历史进度。游标完整性绑定当前scope。进度元数据不会被算作新证据，`read_source_records`也按只读工具处理，不清空无新增证据的循环计数。

数字query仍按原schema真实报错，同时返回相同callId的字符串纠正建议；不自动执行、转换为其他来源或重启整份回执扫描。

对普通PDF任务，初始可见schema优先有界页读取/搜索。工具注册表和权限不变，原文事实字段工具仍可发现；expiry配置仍优先原有事实工具。该调整不使用场景编号或预置业务答案。

只运行关联的回执/压缩/文稿恢复检查（33项）以及新增到尾行为的7项边界检查；没有重跑无关的104项回归。模型回归另存带时间戳目录，沿用07原输入SHA、原指令、硅基流动Qwen/Qwen3.8-27B、每项8请求、150秒请求、600秒任务及20k估算tokens/分钟；旧失败完整保留。模型技术结束和真实文件仍不代表业务验收。
