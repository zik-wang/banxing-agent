# 有界助手转交（独立开发候选）

普通单助手对话中，模型可调用 `request_assistant_handoff`，提出更适合的已启用同事、原因和自己将核对的部分。宿主验证回执后，在同一对话显示三段：A 转交、B 主办、A 辅助核对。

每个原请求最多一次转交；B 和复核阶段没有再次转交工具。只允许业务写入前转交，保留原用户目标；共同最多 24 次模型请求、10 分钟，B 保留 A 的复核预算。权限、资源原件及历史来源门禁照常执行，跨助手不扩大文件范围，不继承挂载目录或额外知识库。审核专项、会议、排程和临时公网合同授权不启用首轮自动转交。

主办交付与复核意见分开保存。A 复核只读，不重写 B 的交付文件；失败、分歧及未完成项保留，不因两个同模型角色同意就提升为事实正确。队列、过期、访问撤销或模型失败时有明确中断记录；不会无限重试或互相转交。

配置可通过 `assistantRouting.enabled=false` 停用新转交。此功能独立于 8197115 网站三项修复候选，不覆盖其冻结代码或正式 8884。工程测试与受控页面演练不代表真实模型会正确决定所有路由。
