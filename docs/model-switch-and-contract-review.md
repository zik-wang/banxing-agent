# 模型切换、附件和合同复核

页面地址保持不变。右上角“公司内网 / 公网模型”可打开连接设置，编辑公司地址、端口及实际模型标识，检测后保存。只作用于后续任务；运行或排队中的任务、会议和上传期间不可切换。连不通不会自动回退到公网。连接检测只读模型目录，不证明推理和审核通过。

文件和历史对话保留。内网材料、派生内容及内网上下文不因切回公网获得外发许可；内网用过的未明确公开资料会保留内网范围。公网合同继续采用原有逐文件授权。真实私人录音不因模型切换而获准外发。公司网络范围由宿主限制为10网段，公网目标沿用已配置HTTPS服务，网页不暴露密钥。

附件区使用按格式区分的图标，图片通过当前对话的授权预览接口显示缩略图，可点击放大。移除只取消引用，原件保留；不支持SVG/HTML作为图片执行。手动选择的材料范围会持久化，后续追问和刷新沿用，未变化的文件不重复上传。提交后收起附件区，避免遮挡对话。

合同专项需选择审核助理和支持的设备采购主合同。私有配置contractReview.localReview启用本地Qwen2.5-1.5B-Instruct LoRA初筛，模型目录及Python环境由维护者提供；不下载或训练27B。初筛只覆盖范围与义务、支付与财务、责任与救济三类局部风险信号，每段最多650字且最多1024输入token，超限和预算未处理范围明确登记。27B承担原有16专题和跨条款审核；后置阶段对照其实际引用的原文，复用已初筛的相同片段，仅补查未读部分。风险信号相同不证明主体关系、日期、法律结论或建议正确；分歧和本地独有候选不自动删除。报告保留各阶段状态、精确原文、模型/适配器指纹及未核范围。

审核答复的“反馈与改进”绑定实际发现、原审核run、原文引用指纹。人工可接受、拒绝、纠正或标记证据不足。反馈先形成不启用候选；补充触发/保障短语、对应专题和至少各2条正反例，经本机测试通过后手工启用。修改候选会使旧测试失效，已启用版本不能原地改写，可停用。规则只触发复核提示，不能执行命令、改工具权限、确定法律效力或在线更新权重。公网不自动接收内部反馈规则。

目前的例测验证程序行为，尚不证明泛化审核准确率或递归学习效果；公司服务器未上线时联合实模验收待补。本地控制条款仍可能产生误报，不将局部微调实验当成完整法律审核能力或已超越27B的证明。
