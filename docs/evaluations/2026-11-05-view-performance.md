# 对话加载与轮询积压修复

本次修复针对页面空闲时仍持续刷新的性能问题。与模型回答质量、任务调用预算无关，本轮未发起模型推理。

行为变化：

- 同一页面最多一个对话轮询请求在途，完成后再安排下一次。
- 运行中的任务间隔约1.4秒刷新，空闲对话约10秒；后台标签页暂停对话轮询并低频检查可见状态，回到页面时刷新。
- 一次同步对话展示共用一份资源索引快照，不再为每个附件和历史成果重复读取并解析全索引。
- 快照不会跨请求保留；写事务重新读取磁盘并使快照失效。新请求仍能发现撤权、归档等变化，打开和下载仍核验实际文件字节。

实际服务前后核查（同一台机器、同三个既有对话、非模型请求）：

- 三个详情 GET：3260 / 2521 / 1588ms → 331 / 272 / 206ms。
- 正常页面轮询的最大同时在途详情请求：5 → 1；采样结束待返回：4 → 0。
- 页面轮询采样：修复前部分响应超过10秒；修复后观测到的三个响应302 / 259 / 305ms。
- 轻量配置接口在详情读取期间：15748ms → 183ms。
- 原有80个对话的附件记录、消息内容及隐藏状态逐项保持一致；抽查两份实际历史文件下载，SHA256与原记录一致。

这些是有限场景的前后观测，不是总体p95、压力容量或业务正确率。浏览器诊断页拦截健康探测，未提交消息；已有用户页面可能仍带来其他正常读取负载。生产目录通过精确前像检查应用最小补丁，并非用开发树整体覆盖。

验证：新增8项性能与边界回归；相关候选检查共62项通过、0失败、1项既有环境条件检查跳过。实际运行目录另重跑新增8项，全部通过。检查包含慢刷新不重叠、错误后可再刷新、请求间撤权生效、跨空间拒绝、下载篡改拒绝、附件与成果保留、写事务不覆盖其他进程已写入内容。

未做本轮模型业务复测，未重写历史材料或结果，未将以上检查视为用户验收。
