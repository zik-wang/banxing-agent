# 合同审核主流程方案与金额修复

[下载工作报告](合同审核主流程方案选择工作报告.docx)

当前选择27B单 Agent承担合同理解、跨条款审查、候选风险分析和报告交付。计算器补强金额核算，本地1.5B保留为三类风险初筛插件。单 Agent不表示只调用一次模型；分批审核、证据检查和报告回读仍由程序编排。

报告结合了两组不同实验，不能混为一个整体准确率指标：

- 合同审核实验：同一组6份短合成合同，27B主审流程完整执行5份，双模型分工完整执行4份。执行完成不证明全部结论正确，也不能推广到任意长合同。
- 金额实验：8个开发合成案例的三组数值或正确拒答均为8/8；初轮严格来源定位均为7/8，重复引文经定向恢复。没有证明财务多Agent增加数值准确率。
