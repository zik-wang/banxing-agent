## 错误类别必须分开

- 取数/覆盖与协议外推：1.5B金额探查少计分项、计划证据不合法，不能简单归为每项单位换算或加法都错。
- 算术/工具：该大额案例已有计算器结果和来源复算证据；工具只对提交项计算，不证明陌生全文无漏项。历史税前/含税口径错例的修复记录不等于整体合同准确率。
- 框架/协议：网页财务work的UNKNOWN_ASSET与恢复开销，以及v1摘要语义未声明，是不同问题；本轮不据旧记录断言当前生产仍有同样bug。
- 服务：历史429/TPM阻断是服务返回，不是计算失败。v1/v2各一次成功响应只证明各次执行成功，不是持续可用性保证。
- 业务复核：v1仍NOT_VERIFIED；v2本条前瞻复核通过。两者都不等于合同可签、陌生材料完整覆盖或生产交付闭环完成。
