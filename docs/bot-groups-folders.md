# 机器人群聊与指定资料文件夹

本版沿用伴行现有页面与处理器，增加站内机器人群聊和受控文件夹连接。既有个人对话、成果和合同审核入口保留。这里的群聊是伴行内的机器人协作，不是微信或飞书群接入。

## 使用

1. 左侧「群聊 → 创建」：起名并邀请 2–4 位启用的助理。
2. 发一条任务，所选成员按顺序各回应一次。点击成员名插入 `@名字`，或通过「回应者」只选择一位。每条回复标明助理和处理过程。机器人不会相互触发无限新回合。
3. 点击顶部机器人或群名称，打开详情。群成员在工作结束后可以调整。
4. 详情中选择需要连接资料的机器人，点击「连接本机文件夹」。可以使用本机目录选择窗口，也可以输入绝对路径。
5. 默认连接只允许本机浏览。外网模式下，只有明确声明为公开或合成材料的连接才会向模型提供文件发现与选用工具；音视频不会经此入口发往公网。
6. 浏览、搜索、勾选文件，再「加入对话」。加入的是校验过的持久副本，原文件不改动；不是整目录上传。
7. 若勾选「允许另存成果」，可将已生成并通过回读的成果复制到该目录的「伴行成果」子目录。重复保存保留已有文件，不覆盖不同内容。也可以让助理通过受控工具另存已验证成果。

群内选定材料对群成员共享。其他成员的回答作为已有工作记录提供，不自动成为事实或证据，也不意味着来自独立模型。现有助理通常仍使用同一配置的 Qwen 模型。

## 边界与可观察性

- 原文件 SHA、选择时指纹、机器人连接权限及导入来源记录在本地。文件变化、移动、断开、路径越界或权限不符会明确报错。
- 不跟随目录内的符号链接、目录联接；隐藏配置、密钥、模型权重及开发依赖等不参与目录发现。
- 当前目录遍历上限 5000 项、深度 20；分页最多 100 项。单个导入文件最多 50 MB，页面每批选择最多 20 份。达到范围限制时返回未完整遍历状态。
- 断开连接阻止后续原目录读取，但保留此前已授权导入的副本和历史成果。全局归档、撤权仍使用原工作空间机制。
- 群消息使用现有串行队列和调用预算；已开始的消息不能局部改写。停止群任务时停止当前处理并取消尚未开始的成员回应。
- 所有成员失败时整体显示失败；有真实部分回应或成果才显示部分完成。接口目录可访问不代表推理已成功。
- 原生文件选择窗口需在本机交互使用；其他系统可直接输入目录。无远程磁盘、账号或外部群权限扩展。

## 测试说明

`tests/v8-bot-groups.test.mjs` 验证串行调度、邀请范围、@、队列修改/删除、停止、重启、失败状态和分支成员保留。

`tests/v8-folder-connections.test.mjs` 验证持久授权、目录发现、外发分类、文件变化、路径边界、链接拒绝和不覆盖的成果复制。

`tests/v8-connected-folder-tools.test.mjs` 验证真实工作空间导入、回绑、撤权及实际文件 SHA。调度测试使用明确的离线子进程替身，不冒充真实模型运行。

本轮页面与服务记录位于操作者 QA 目录 `grok-bots-workspace-20261101`。真实 Qwen 群任务与离线合成文件的页面测试分别记录；模型超时不会被当作协作能力通过。训练权重、密钥、个人文件和这些运行数据不属于源码交付。
