# 可复用的矢量原图转 CAD 路线

本轮新增的是原生矢量 PDF 转写工具及独立检查器。DeepSeek 在现有 Harness 中读取原图与独立功能说明、建立尺寸配对并实现工具；没有改用其他模型。模型界面声明为 DeepSeek-V4.1-Flash 1017 High，未取得供应商原始模型回执。

## 运行

在 `cad-harness` 目录、已安装 `requirements.txt` 的 Python 环境运行。每个案例目录包含获准使用的 `original.pdf` 和单独的 `functional_modules.md`。下面只执行离线工具，不调用模型。

```python
from cad_harness.vector_batch import run_case

record = run_case("/absolute/path/to/case")
```

`run_case` 从该案例 PDF 的箭头与明确毫米标注估计比例，不使用其他案例尺寸。输出纸面及实际毫米 DXF、真实 DXF 渲染、来源映射、构建记录和功能图。支持当前产品族的轴向尺寸配对；没有一致的双向锚点时返回 BLOCKED。不要将自动配对一致性当作独立正确性证明。重新运行会覆盖同名输出：实际流程应在每次运行前另存版本及 SHA256；本轮 N09/N10 的早稿未留存，不能声称初次直接通过。

四个默认功能角色只适用于本轮说明。其他案例必须按真实功能说明传入模块名称，并单独核对连接关系；固定四框不证明任意功能说明都被理解。现有 stdio MCP 的工具清单没有自动增加此路线，不应声称该接口已经完成 MCP 端到端接线。

## 独立检查与通过口径

1. `pdf_anchors.candidates` 只提供原图观察候选，不包含验收答案。
2. `pdf_source_audit.audit_source` 独立读取原始 PDF 与保存后的 DXF，核对源线段、隐式填充闭边、文字内容与基线位置；不依赖转写器自己报告的实体数。尺寸尺度与功能语义仍须另外检查。遇到不支持的源操作保留未验证状态。
3. 实际重开 DXF，核对毫米单位；以原图标注、对应箭头和主轮廓来源定位做尺寸检查；功能图核对系统边界、模块名称、模块数量及连接。
4. 用户最新口径为约 **1% 相对误差**。小于阈值后停止千分位或像素级优化；缺失视图、孔槽、错误连接、关键文字不可读仍拦截。不得用平均误差掩盖结构错误。

`vector_build` 内的可选 `bbox_check` 在全图寻找接近期望包围盒，不能作为主体尺寸通过证据。构建记录中四舍五入的测量也不能代替独立未舍入测量。当前 `pdf_source_audit` 主要覆盖线段/折线路线，不能据此泛化为曲面、三维实体或全部 PDF 路径的独立验收。

## 已验证范围

新十图均为同一公开厂商、同一安装座产品族的不同原始矢量 PDF。本机独立复核为 9/10 技术通过；N10 主轮廓定位尚待核实，保留 REVIEW_REQUIRED。已通过案例检查项最大相对误差约 0.04%。这是源矢量转写路线的同族验证，不是独立位图重建或跨行业泛化成绩，也不是制造放行。

字体、标志填充和折线逼近有可见渲染差异。图纸上的螺纹深度文字虽保留，三维螺纹实体及未标注制造定义没有得到验证。保留原图的参考用途说明。
