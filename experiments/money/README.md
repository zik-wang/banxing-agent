# 金额核验实验与修复

仅在独立分支使用。本实验不替换现有8884服务，不包含私有配置或模型权重。

```
node --test tests/money-calculator.test.mjs
node experiments/money/run.mjs <新输出目录> <宿主私有配置JSON> <基线SHA>
node experiments/money/replay-historical.mjs <新历史回放runtime目录> <历史QA合成发票XLSX>
node experiments/money/report.mjs <实验输出目录>
```

模型配置沿用宿主chat字段，密钥通过apiKeyFile/apiKeyEnv读取。每轮最多48次实际请求、两路并发、单次90秒、不自动重试。已有结果回放不会重新推理。对同一目录重启会保留已有outcome，但budget计数仅表示本进程，跨进程费用应按磁盘API回执累计；不得宣称具备生产级累计预算。

参考答案仅由离线评分读取，不发送模型。8例是开发合成参考，包含历史税前/含税错例变体，不是独立法律Gold。三组使用同一输入与JSON协议：现有27B语义计算、单Agent+计算器、独立财务会话+取数对照+计算器。同一27B的两个角色不是独立能力模型。

原始46请求结果数值均通过，但重复短引文的来源定位不合格。补充通用唯一定位约束后，对相同税额案例三组补做6请求；初轮与恢复分别统计。报告脚本以当前严格证据校验器离线复算旧输出，不能将复算冒充新模型调用。

生产改动：合同显式金额识别支持元/万元/亿元；报销汇总按含税/税前口径选列，不再取第一个“金额”列。calculate_money只读取宿主授权资产及已取回PDF文本页，记录原件SHA、原文跨度和算式；扫描件不因此得到OCR认证。金额取数范围仍需单独核对。

金额使用BigInt有理数计算，末端两位小数四舍五入；仅支持sum/subtract/percent，不是任意表达式执行器。不执行用户代码、不加载eval、不跨币种折算。结果保存在resultId，export_document(result_ids=[...])直接导出该程序结果并回读，避免重抄金额。整张Excel沿用table_statistics，不能用文字金额工具取代类型与全表覆盖校验。

最终选择：默认单Agent+计算器。小样本没有证明数值准确率优于27B；确定性校验、可复算性和引用检查才是已验证收益。财务协作未观察到数值增益，调用更多，不作为默认。复杂业务口径分歧仍可请求财务复核。
